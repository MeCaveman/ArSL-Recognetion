# ArSL Recognition — Project Reference

## Overview
Real-time Arabic Sign Language (ArSL) recognition system using **YOLO26** object detection with a **PySide6** GUI. Recognizes 32 Arabic sign language letters.

## Model Details
- **Architecture:** YOLO26s (small, ~22M params)
- **Trained:** 50 epochs on ArSL21L dataset
- **Input size:** 640×640
- **Weights:** `runs/train/arsl21l/weights/best.pt`
- **Confidence threshold:** 0.45
- **Inference device:** CPU (configurable to GPU via `DEVICE = 0`)

## 32 Classes (YOLO class names)
`ain, al, aleff, bb, dal, dha, dhad, fa, gaaf, ghain, ha, haa, jeem, kaaf, khaa, la, laam, meem, nun, ra, saad, seen, sheen, ta, taa, thaa, thal, toot, waw, ya, yaa, zay`

## App.py Architecture
- **ArSLMainWindow** — 1080×700 fixed-size main window
- **TopBar** — Title (EN+AR), logo, settings button → SettingsDialog
- **WebcamCanvas** — 700×480 rounded widget, grid placeholder, FPS overlay
- **LetterPanel** — 320px right panel: Arabic glyph, hand sign photo, AR/EN names/descriptions, audio player with auto-play after 1.5s hold
- **StatusBar** — Color-coded status (idle/recognizing/paused/stopped/error)
- **SettingsDialog** — Camera selector (0-3) + About section
- **WebcamThread** — OpenCV capture → YOLO predict → emits frame+detection+FPS
- **ImageInferenceThread** — YOLO predict on static image

## LETTER_DATA (App.py lines 65-98)
32 entries, each with: `arabic`, `name_en`, `name_ar`, `phonetic`, `desc_en`, `desc_ar`

## Sounds
32 MP3 files in `assets/sounds/` named `{key}_arsl.mp3`. Generated via `LettersGenerator.py` using gTTS.

## Fonts
- Inter (auto-downloaded from Google Fonts) — UI sans-serif
- Material Icons (auto-downloaded) — icon glyphs
- NotoSansArabic (bundled, 31 variants) — Arabic text

## Dependencies (pyproject.toml)
- opencv-python >=4.10.0.84
- pillow >=10.4.0
- pyside6 >=6.8.0
- torch >=2.11.0, torchaudio, torchvision
- ultralytics >=8.3.0
- Python >=3.12, <3.15

## How to Run
```bash
python App.py
```
Training: `python src/train.py` (update `config/data.yaml` dataset path first)

4. **Pulsing status dot** — StatusBar dot uses `QPropertyAnimation` on `QGraphicsOpacityEffect` (0.3→1.0, 1600ms, InOutSine, infinite loop) when webcam is active
5. **Gradient backgrounds** — TopBar uses `qlineargradient`, main window uses subtle dark gradient (`BG`→`BG_GRAD`)
6. **Pressed button states** — all interactive buttons (`:pressed` pseudo-state) have visual feedback (offset + accent color)
7. **Refined audio slider** — gradient fill, larger hover handle (12→14px)
8. **Improved placeholders** — webcam placeholder has centered dot + glow gradient, letter panel uses "✋" icon + hint text
9. **Gradient dividers** — `_divider_h()` uses gradient (transparent→border→transparent) instead of flat line
